\### 2026-09-10



Goal-Date Listening Demo を初めてWeb公開。



スマートフォン上で以下の一連の動作を確認。



\- 聞き取れなかった箇所の登録

\- 弱点理由の記録

\- 復習時の弱点再提示

\- × / △ / ○ による自己評価

\- 目標日から逆算した次回復習日の提示

### 2026-09-16

Prototype 09（音声入りWebデモ）を公開。

GitHub Pages上でスマートフォン実機テストを行い、以下の一連の動作を確認。

- AI合成音声の再生
- 英文の弱点箇所の登録
- 弱点理由の記録
- 文脈音声の再生
- 復習時の弱点箇所・理由の再提示
- × / △ / ○ による自己評価
- 目標日から逆算した復習スケジュールの再計算

PCで作成した試作品をWeb公開し、URLからスマートフォンで音声を含む一連の学習フローが動作することを確認した。
